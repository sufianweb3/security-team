## Summary
get_invoice looks up an invoice solely by the client-supplied id. owner_id is fetched and even returned, but never compared to the session user. Elsewhere (apply_coupon) the code scopes queries by current_user().id, showing the intended ownership pattern.

## Evidence

row = db().execute("SELECT id, owner_id, total FROM invoices WHERE id = ?", (invoice_id,)).fetchone()

return jsonify({"id": row[0], "owner": row[1], "total": row[2]})
