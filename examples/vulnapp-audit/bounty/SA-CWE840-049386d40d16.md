## Summary
apply_coupon selects single_use but never checks or records redemption, and applies the percentage to the already-discounted cart total. Repeating the request reduces the total geometrically toward zero.

## Affected component
app — app/app.py:77

## Evidence
```
coupon = db().execute("SELECT percent, single_use FROM coupons WHERE code = ?", (code,)).fetchone()
new_total = cart[1] * (100 - coupon[0]) / 100
db().execute("UPDATE carts SET total = ? WHERE id = ?", (new_total, cart[0]))
```

## Impact
Fraudulent discounts / goods obtained below price.
